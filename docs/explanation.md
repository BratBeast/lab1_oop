# Пояснення коду

Починати читати проєкт зручно з `Main`, потім перейти до `Appliance`
та `Apartment`.

## Як проходить виконання

У `main` створюється об'єкт `Main` і викликається `run`.
У `run` створюються квартира й п'ять приладів. Вони додаються до списку.
Чайник Philips і телевізор Samsung підключаються та вмикаються.
Пральна машина лише підключається, тому її поточна потужність дорівнює нулю.

Далі програма виводить список, рахує загальну потужність, сортує прилади
і виконує пошук. Наприкінці чайник від'єднується, а сума перераховується.

## Навіщо потрібен Appliance

У всіх приладів є назва, потужність і стан. Щоб не повторювати ці поля
та методи в кожному класі, вони записані в `Appliance`.

Клас абстрактний: створити `new Appliance(...)` не можна.
Потрібно створити конкретний прилад, наприклад `new Kettle(...)`.

`private` закриває прямий доступ до полів з інших класів.
`final` біля характеристики означає, що після створення об'єкта
посилання або значення цього поля не можна переприсвоїти.
Стани `pluggedIn` і `switchedOn` змінюються через методи.

## Успадкування та поліморфізм

`Kettle extends Appliance` означає, що чайник є електроприладом.
Він отримує спільні методи й додає власне поле об'єму.
Виклик `super(...)` у конструкторі передає назву та потужність
конструктору батьківського класу.

Метод `getDescription()` має різну реалізацію в кожному підкласі.
Це показує поліморфізм:

```java
Appliance appliance = new Kettle("Philips", 2000, 1700);
System.out.println(appliance.getDescription());
```

Хоча змінна має тип `Appliance`, виконується метод класу `Kettle`.
`@Override` допомагає компілятору перевірити, що метод перевизначено правильно.

## Як працює Apartment

`List<Appliance>` дозволяє зберігати чайники, телевізори та пральні машини
в одному списку. `ArrayList` - реалізація такого списку.
Квартира містить прилади, тому вона не успадковує `Appliance`.

У `getTotalCurrentPowerWatts()` цикл проходить по всіх приладах
і додає їхню поточну потужність. Тип `long` дає більший діапазон суми,
ніж `int`. Для прикладу: 2000 + 120 + 0 + 0 + 0 = 2120 Вт.

У `sortByPower()` метод `sort` сортує список.
`Comparator.comparingInt(Appliance::getRatedPowerWatts)` означає:
порівнювати прилади за числом, яке повертає `getRatedPowerWatts()`.
Подвійна двокрапка тут є посиланням на метод.

У `findByPowerRange()` цикл перевіряє кожен прилад:

```java
if (powerWatts >= minWatts && powerWatts <= maxWatts) {
    result.add(appliance);
}
```

`&&` означає, що обидві умови мають виконуватися одночасно.
Наприкінці повертаються всі знайдені прилади.
`List.copyOf(...)` повертає незмінну копію списку, тому виклик
`clear()` для отриманого списку не видалить прилади з квартири.

## Що варто перевірити самостійно

1. Змінити потужність Philips на 1500 Вт. Початкова сума стане 1620 Вт.
2. Після `washer.plugIn()` додати `washer.switchOn()`.
   За початкових значень сума стане 4320 Вт.
3. Змінити діапазон пошуку на 90-120 Вт: знайдуться обидва телевізори.
4. Прибрати `kettle.plugIn()`, але залишити `kettle.switchOn()`:
   програма повідомить, що спочатку потрібно підключити прилад.

Кожну зміну перевіряти окремо, повертаючи попередні значення.
Тести демонстрації використовують початкові дані, тому після їх зміни
очікувані результати відповідних тестів теж потрібно оновити.
